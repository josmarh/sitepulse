## About SitePulse

Monitor websites from one dashboard, identify problems early, and keep clients informed through email alerts and shareable status pages.

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

### Features

| Feature | Description |
|---------|-------------|
| Uptime monitoring | Check whether a website responds |
| SSL monitoring | Track certificate expiration |
| Domain reminders | Notify users before domain expiration dates |
| Response-time tracking | Record how quickly a website responds |
| Broken-link checker | Find broken links on a website |
| Scheduled checks | Run checks automatically |
| Email notifications | Alert users about detected problems |
| Status pages | Display service availability |
| Reports | Show historical uptime and response times |
